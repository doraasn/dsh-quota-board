# dsh-quota-panel

DSH（DeepSeek Harness）侧栏额度看板。在侧栏底部显示两张卡片：

```
┌─ AstraHub              ¥198 / 391
└─  ← 供应商：名称 + 余额 / 总额度
┌─ Codex                     93% / 19:54
│  91% 周 · 10/27 14:54    重置 · 3 次
└─  ← Codex：两行，第一行 5 小时额度 + 重置时间
```

- **每个供应商一张卡片**，**顺序与设置页一致**，在设置里拖动 `⠿` 手柄即可调整。
- **设置面板**左侧新增「额度看板」一节：每个供应商一张设置卡片，可任意增删。
- **右键面板**打开菜单：勾选要显示的卡片（至少保留一项）。
- 鼠标悬停金额/数字可看明细说明。
- 侧栏折叠时退化为一个状态色圆点。

## 数据来源

| 卡片 | 来源 | 说明 |
|---|---|---|
| Codex | 本机 `codex` CLI 的 JSON-RPC `account/rateLimits/read` | 需要本机装了 Codex CLI 并已登录；CLI 退出或升级后插件会自动重新拉起（每 10 秒重试） |
| 中转供应商 | `{baseUrl}/dashboard/billing/usage` 与 `/subscription` | 任意 OpenAI 兼容中转站（new-api / one-api 系）均可，数量不限；余额 = 总额度 − 已用 |

两个接口都是只读的。API Key 只在主机侧用于请求，**不会发送到前端**。

## 安装

1. 侧栏 → **插件** → **添加插件**
2. 粘贴压缩包的**绝对路径**，例如
   `C:\Users\你的用户名\Downloads\local-dsh-quota-panel-0.1.0.tgz`
   （也支持本地目录绝对路径、Git 地址、npm 包名）
3. 安装完成后启用该组合包；若提示需要重启，重启 DSH。

## 配置

**设置面板**（界面左下角/设置入口）→ 左侧导航「额度看板」。

一张卡片 = 一个供应商，可任意增删：

| 类型 | 数据来源 | 卡片显示 | 需要填 |
|---|---|---|---|
| **中转站** | `{地址}/dashboard/billing/usage` 与 `/subscription` | 剩余额度 + 总额度 | 供应商名称、中转地址、API Key |
| Codex | 本机 `codex` CLI 的 JSON-RPC `account/rateLimits/read` | 5小时 / 周 两个窗口 + 重置次数 | 只要供应商名称 |

底部按钮：**预设（AstraHub、Codex、DeepSeek、Z.AI，按字母排序）在前**，然后是 **「+ 自定义」**（空白供应商）。

- **预设点一下就加出一张预填好的卡片**，不用记地址和字段路径。
- **数量不限**：同一个预设可以加任意多张（多个账号就加多张），**名称都可以改**。
- **Codex 卡**没有地址和密钥，但有名称（可改成「Codex 工作号」之类）和 4 个显示开关。
- 中转供应商数量不限。卡片右上角 **「删除」** 移除。改完点 **保存**，立刻重新拉取，不需要重启。
- 每张卡标题右侧、「删除」左边有一个**开关**（无文字）：关掉就在侧栏隐藏，**立即生效**、按设备保存，不走「保存」。最后一张卡不能关。

**卡片默认折叠**，只显示一行摘要（`⠿ 名称  地址 …… 删除 ▸`），点这一行展开。展开后每个控件一行：`名称 / 地址 / API Key`，标签在左、输入框在右，和卡片标题同一列。新添加的卡片会自动展开，方便直接填。

**Codex 卡展开是 4 个显示开关**（5 小时额度 / 周额度 / 重置时间 / 重置次数）：只决定侧栏那张卡显示哪些内容，**改完立即生效**，按设备存在 `localStorage`，不走「保存」。

**拖动 `⠿` 可调整顺序**，侧栏和右键菜单都按这个顺序显示；顺序随「保存」一起落盘。

预设的 **Codex 卡片固定排在最前**（它没有可填项）；其余供应商按添加顺序排在后面。

- 中转卡片要填地址才有意义；完全空白（无名称/地址/密钥）的卡片保存时会被丢弃。
- 全删也允许保存，重启后不会又冒出一个默认供应商。
- 首次使用（没保存过配置）默认给两个：`AstraHub`（中转）+ `Codex`。

关于密钥：

- **API Key 不会回传到浏览器**。主机侧只返回"是否已设置"，输入框始终是空的（占位提示会写明"已设置，留空则不改"）。
- 密钥保存在本机 `~/.dsh/storages/quota-panel.json`，与 DSH 自己的凭据文件分开存放，不会影响其他插件。
- **每个供应商只用自己卡片上的密钥**。没填就是没填，不会去借用别家的 key（旧版把密钥放在 `.dsh/.credentials.yaml` 并按名字引用，这个字段已从界面移除，只在老配置里作为兜底生效）。
- 想换密钥：直接填新的点保存；想彻底不用：删掉这张卡片。

### 字段映射（可选，用于非标准中转站）

默认按 new-api / one-api 系的字段取数：

| 显示 | 默认路径 | 系数 |
|---|---|---|
| 已用金额 | `usage.total_usage` | ×0.01（接口返回的是"分"） |
| 总额度 | `subscription.hard_limit_usd` | ×1 |
| 剩余 | 留空 = 总额度 − 已用 | — |

中转卡片里点 **「字段映射（可选）」** 展开：

1. 点 **「获取返回」** —— 主机真的去请求该站的 `/dashboard/billing/usage` 和 `/subscription`，把**原始 JSON 原样显示**出来（只读展示，密钥不回传）。
2. 照着返回里的字段名，把 `已用金额` / `总额度` / `剩余` 三行填成你需要的路径，例如 `usage.total_usage`、`data.quota`。
3. 右边那个数字是**系数**：接口返回"分"就填 `0.01`，返回"元"就填 `1`。
4. 填写后下方会立刻显示 **按当前映射解析：已用 ¥… · 总额度 … · 剩余 ¥…**。解析不出来就是路径不对，换一个即可。
5. **留空即用默认**；点 **「恢复默认」** 一键清空三行。

路径支持嵌套和数组下标，例如 `data.items.0.quota`。三项里只有"剩余"可以真的留空（表示用总额度减已用）；如果你想把剩余直接读某个字段，填上它就会覆盖计算值。

映射随卡片保存，写进 `quota-panel.json` 的 `map` 字段。

> 只支持上面这两个接口。如果你的中转站余额来自**别的路径**（比如 `/api/user/self`），点「获取返回」会失败——告诉我要请求哪个 URL、返回什么结构，我把探测地址也做成可配的。

### 不用界面时（自动化/脚本）

也可以用环境变量或 YAML，但**只影响"默认供应商"**——一旦在界面里保存过供应商列表，就以界面为准。

- 环境变量：`ASTRA_HUB_BASE_URL`、`ASTRA_HUB_CREDENTIAL`
- 插件 config：编辑安装目录下的 `cordis.patch.yml`
  ```yaml
  - insert:
      - id: quota-panel
        name: '@local/dsh-quota-panel'
        config:
          astraBaseUrl: https://your-relay.example.com
          astraCredential: YOUR_RELAY_API_KEY
  ```
- 密钥放在 `~/.dsh/.credentials.yaml`（`astraCredential` 指向的名字）：
  ```yaml
  refs:
    ASTRA_HUB_API_KEY: sk-你的中转站密钥
  ```

主机侧只读取凭据文件，不写回，也不把值传给前端。**这条只在没在界面里填过密钥时生效**；卡片上填的密钥优先。

### 地址怎么填（一个输入框，三种写法）

| 地址 | 实际请求 |
|---|---|
| `https://relay.example.com` | new-api 两段式，自动补 `/dashboard/billing/usage` + `/subscription` |
| `https://relay.example.com/dashboard/billing/usage` | 同上（粘贴其中一条也能认出，会补成两段） |
| `https://api.deepseek.com/user/balance` | **只请求这一个地址**，返回的整份 JSON 作为字段映射的根对象 |
| `https://x/usage.php https://x/sub.php` | **两个完整地址**（空格或逗号分隔），依次作为「用量」「总额度」接口 |

非标准中转站如果路径不是 new-api 那两条，就用第四种写法，避免猜。

**DeepSeek 官方余额**配置示例：

| 字段 | 值 |
|---|---|
| 地址 | `https://api.deepseek.com/user/balance` |
| API Key | 你的 DeepSeek key |
| 字段映射 → 剩余 | `balance_infos.0.total_balance`（系数 1） |
| 已用 / 总额 | 留空（官方接口不提供） |

返回结构（[官方文档](https://api-docs.deepseek.com/api/get-user-balance)）：

```json
{ "is_available": true,
  "balance_infos": [{ "currency": "CNY", "total_balance": "110.00",
                      "granted_balance": "10.00", "topped_up_balance": "100.00" }] }
```

配好后点 **「获取返回」** 能看到原始 JSON，再点 **保存**，侧栏卡片显示 `¥110`（没有总额度就不显示 `/ 总额`）。

也可以直接用底部的预设按钮（AstraHub / Codex / DeepSeek / Z.AI）：加出来的卡片地址和字段路径都填好了，只需要补 Key 再保存。以后要加别的预设，在 `PRESETS` 数组里加一项即可，按钮会自动按字母序排在「+ 供应商」前面。

**自定义卡片的示例用的是 DeepSeek 的信息**：地址占位符 `https://api.deepseek.com/user/balance`，映射提示里也给了 `balance_infos.0.total_balance` 这个例子，照着改成你要填的即可。

## 显示项

**右键面板**（折叠态右键圆点也行）打开菜单，只管"显示哪几张卡"：

- **Codex** 加上每个供应商一项，顺序与卡片一致
- 新加的供应商默认显示，不用回到这里勾选
- 至少保留一项：只剩一项时它的勾选框会置灰，无法取消
- 点面板外部或按 `Esc` 关闭
- 配置供应商在设置面板里

选择保存在浏览器 `localStorage`，按设备生效。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 升级后某张卡片消失 / 只剩一张 | **先重启 DSH**。主机端代码在启动时加载，客户端每次刷新页面都重新取，两者容易一旧一新 |
| 某张供应商卡显示 `--` | 设置面板 → 额度看板，检查该卡的地址与密钥；密钥留空不会清除已保存的 |
| 面板底部提示"额度不可用" | 该供应商地址不可达，或该站不是 new-api 系（没有 `/dashboard/billing/*` 接口） |
| 保存后数字没变 | 保存会自动重新拉取；若仍无变化，看地址是否可达 |
| Codex 卡显示 `--` | 本机没装 Codex CLI，或它没登录（`codex login`）。不需要就在设置里删掉这张卡 |
| Codex 数字不动 / 一直停在旧值 | 已修：插件每 10 秒重试拉起 `codex app-server`。若装了 0.8.2 之前的老版本，重启 DSH 即可 |
| 装了但侧栏没出现 | 组合包没启用，或需要重启 DSH（Host 侧改动不会热加载） |
| 改了环境变量/config 没生效 | 界面里保存过供应商列表就以界面为准，删除卡片即可回到默认 |

在 DSH `0.2.1-rc.2`（Windows 桌面版）上开发与验证。未声明 `engines.dsh`——因为无法逐一验证旧版本，写一个猜的版本范围反而可能挡住能用的安装。

## 卸载

侧栏 → 插件 → 找到该组合包 → 移除。`~/.dsh/.credentials.yaml` 里的密钥不会被改动，需要的话自行删除。

## 悬停详情

鼠标停在侧栏任意额度卡上，右侧弹出官方样式的详情卡（卡片填充色、20px 圆角、标题 15px/600、键值行）：

- Codex 卡：5 小时、周、5 小时重置、周重置、重置次数
- 中转站 / 官方 API：余额、已用、总额、今日

右侧放不下时自动翻到卡片左侧。

## 安装（国内网络）

DSH 安装 git 插件时是**由本机直接去 GitHub 下载 tarball**，不经过插件市场或镜像源。所以没有代理的网络会报「无法连接 github.com」。

三种方式任选：

| 方式 | 做法 |
|---|---|
| 压缩包直链（CDN）| 在插件市场选「压缩包」，填 https://cdn.jsdelivr.net/gh/doraasn/dsh-quota-board@main/dist/dsh-quota-board-0.11.5.tgz |
| npm | 发布到 npm 后，在市场里直接按包名安装，走你本机配置的 registry（npmmirror 可达）|
| 代理 | 让 DSH 走代理后再从市场安装 |
